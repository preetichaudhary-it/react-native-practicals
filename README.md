## 💻 Getting Started

Follow these steps to set up and run the projects locally on your machine.

### Prerequisites

Ensure you have the following installed:
* [Node.js](https://nodejs.org) (LTS Version)
* [Git](https://git-scm.com)
* Expo Go App installed on your physical mobile device ([Android](https://google.com) / [iOS](https://apple.com))

### Installation Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/preetichaudhary-it/react-native-practicals
   ```

2. **Navigate to the specific project folder** (e.g., `student-profile`):
   ```bash
   cd student-profile
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```

### Running the Application

1. **Start the Expo development server:**
   ```bash
   npx expo start
   ```

2. **Open the app on your device:**
   * Scan the **QR code** displayed in your terminal using the **Expo Go** app (Android) or your built-in camera app (iOS).
   * Ensure your computer and mobile phone are connected to the **same Wi-Fi network**.
